# Supabase

- `schema.sql` : tables, index/contraintes, fonctions de mise à jour et politiques Row Level Security (RLS).
- Le schéma doit être exécuté depuis le SQL Editor du projet Supabase.
- La clé `service_role` ne doit jamais être exposée dans les fichiers front-end.
